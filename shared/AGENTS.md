# Shared contracts
- Read root AGENTS.md. These modules serve both studio and public reader; avoid browser-only dependencies in server/build imports.
- Validation is a security boundary: allow supported types/marks/URLs only, bound input complexity, and escape rendered user content.
- Keep editor preview and public rendering consistent. Preserve readable HTML, logical reading order, transformed bounds, group attachment, and reduced-motion behavior.
- Schema changes require explicit compatibility decisions and tests for imports, server validation, and published output.
- Entry v2 is the only supported entry format; it requires `notebook-900x1200-v1`, with element coordinates relative to the 792×920 composition region. Archive-envelope version stays 1. Reject unknown versions/formats without mutating recovery content.
- Notebook geometry and ink bounds are shared pure checks. Browser measurement uses canonical renderer/CSS and self-hosted Kalam after fonts load; do not accept serialized HTML or client fit claims as publication proof.
- New text may opt into self-hosted Caveat handwriting and an allowlisted size; preserve optional font/fontSize/fixedHeight through cleaning/recovery. Missing font/size retains legacy Georgia 28px/38px, and missing fixedHeight retains legacy auto-height. Fixed boxes retain authored dimensions and auto-fit their rich contents using shared/text-fit.js, matching editor, physical reader and canonical validation. Preferred fontSize and document content remain unchanged. Canonical fit rejects impossible boxes and unavailable fonts; accessible flowing reading remains at the preferred readable size. Keep Georgia as the legacy body preference and the self-hosted Gelasio metric-compatible fallback available to builds/readers without Georgia. Font loading errors block fit proof while preserving local draft/export access. Local recovery may retain ink beyond the repository save limit.
- Book page index 0 is blank inside cover; entry index n is physical face n+1. Camera scaling never changes stored geometry. StPageFlip 2.0.7 internals are isolated in its adapter; completion callbacks must defer scene navigation and animation timestamps cannot precede start time. Dispose effects, captures and engine loops.
- Paper palette preferences are browser-local via `shared/paper.js`, separate from entry documents; only light allowlisted colors are supported. Its wordless page-shaped trigger opens native popover swatches with accessible names, pressed/checkmark selection and Escape/light dismissal; share `paper.css` with studio and reader. Tooth stamps use ordinary drawing strokes, not a new object type.
- `shared/book/timing.js` owns action durations shared by scene, page-turn adapter, CSS variables and motion tests. Audio follows the turn midpoint. Transient bursts and landing animations must stop on disposal, tab hide and reduced-motion changes; immediate deep links have no flourish. Chain anchors sit on the ring, with mount/bail geometry connecting cover to charm artwork.
- Page folds are inert spans on physical paper faces, included in opening/closing/curl clones; root-level corner buttons provide unscaled screen hit targets without separate visible icons. Committed turns use restrained stepped timing and bounded, banded shadows in the pinned adapter; drag tracking remains continuous. During opening, clip the stationary stack backing to the gutter/right paper and end the reverse cover at the canonical gutter. Keep the mounted paper slightly separated from its backing to avoid coplanar artifacts. Opening paper is an inert cover-mounted clone aligned with the canonical resting left page; remove it on settle/interruption/disposal without remounting semantic content. Page drags work over text, ink and photos; recognized drags must suppress click-to-open/focus. Native photo dialogs restore focus, support keyboard opening/dismissal, and download the served image.
- Desk sprites use the original whole-pixel pipeline (`scripts/desk-art.mjs` through `book-assets.mjs`). `book/prop.js` shares pickup/move/release, keyboard arrows, capture cancellation, resize clamps and disposal for all six objects. Keep the menu independent of book translation. Desk dragging has no rectangular outline, text selection or tap flash; keyboard focus uses a sprite silhouette glow. Do not remove focus feedback from player links/controls. Hide desk props/effects when the camera focuses a page so they cannot cover reading/photo targets; Zoom out restores the desk. Lighter particles/glow run only while held under normal motion, fade before canvas edges and stop when paused/hidden/disposed; reduced motion uses a stationary flame. Reverse-cover clipping/edge geometry must match the resting gutter.
- Optional entry `music` displays the top three artists and three songs; validation retains older lists of up to five without dropping recovery data, each with a name and optional matching Spotify artist/track URL and allowlisted artwork. `music.js` owns canonical URL/artwork validation; `book/music-player.js` and the accessible reading fallback display only the selected/published entry's authored lists. Spotify artwork stays unmodified, links back and carries official attribution. The player uses the unmodified official black full logo on a light pink panel, with its exclusion zone and minimum size; never redraw the wordmark as digital text. Anchor its badge to the LCD bottom and reserve space so lists do not overlap it. The MP3 housing drags from non-control areas; its heart button toggles the music screen, and controls/links never start a drag.
- `book/herbs.js` owns the scene-local visual jar → opening/closing grinder → click-only spin → open dust → filled pipe → automatic lighter ignition/return → smoke/reset sequence. Invalid/cancelled drops preserve their source; keyboard buttons perform equivalent transfers. Keep flow explanations screen-reader-only. The grinder opens to receive buds, closes with them inside, spins on a subsequent click (never a drag), then opens with liftable dust. Filling the pipe summons the actual lighter via cancellable finite Web Animations; return must restore its exact resting position and remove filled animations. Smoke has bounded buoyancy/drift/inherited velocity, a finite tail, and no idle loop. Pause/hide/resize interrupts smoking back to packed; reduced motion completes instantly. The lighter remains manually usable, with delayed ignition after pickup spin and flame/burner/glow sharing one rigid tilt frame. Place both lighter images explicitly at left zero; the flame sits over the central burner vent. The circular glow must fade fully inside its own bounds, with gentle intensity variation and no independent horizontal drift. Book contact-shadow geometry animates with the cover and settles before opening/closing state removal.
