## Full-quality PNG (structural Worker, build decode)

Local and simulated evidence only. Nothing has been deployed.

G1 (local Windows workerd via Miniflare): worst-case near-incompressible 1600×1600 RGBA PNGs. Initial candidate paths exceeded 10ms. At 3MB the existing JS chunk-loop body read alone cost about 9–10ms, and the full path cost 19–25ms with Worker CRC or 14–16ms without it. Measured at 0.5/1/1.25/1.5/1.75/2/3MB, CRC-off process CPU was 2.8/5.0/6.3/8.1/10.3/10.3–12.2/15.3ms. The lean path brought `node tests/desktop-media-workerd.mjs` to 6.25ms process CPU per request for the maximal 2,996,004-byte fixture and 8.44ms for 2048 IDAT chunks, over 100 requests each. An informational local SHA-1 run, which production does not compute because GitHub returns the blob SHA, measured 8.44ms. The lean path is: native framed-body read, structural-only checks, zero-copy, and a string-built base64 body. V8 sampled active time had a median of 8.5ms but a p95 of 26.6ms over 25 profiled samples. That tail includes profiler/GC sampling, which leaves production headroom unproven. Heap stayed far below 128MB.

G2: Sharp alone accepted bad CRC, inflate bomb, trailing zlib data, truncated input, trailing bytes, APNG, RGB, and oversized dimensions. The build therefore runs the shared full `cleanPng` decode on Git PNGs. Unit tests prove the full decode rejects every negative, including a truncated IDAT stream. `tests/blog-build.mjs` proves an inflate-bomb PNG fails the publish build and a 1600px / ~3MB PNG is published byte-identical.

Checks run under bundled Node 24: `npm test` (74 passed), `npm run test:server` (21 passed), `node tests/desktop-media-workerd.mjs`, `node tests/desktop-media-browser.mjs` against local Vite (Chrome), `node tests/cloud-csp.mjs` (Edge, compiled assets), `node tests/cloud-browser.mjs`, `npm run build`, `node tests/blog-build.mjs`, `node tests/public-browser.mjs`, and a real-content `npm run build:blog` (0 entries/photos; the repository has no published content).

The browser suite verifies the following. A 2000px PNG is capped at 1600px. Smaller PNGs are not resized. Incompressible 2400px noise steps down to ≥660px and stays PNG. Alpha is exact. Opaque pixels are lossless. Upload bytes equal the single import encode. In the studio it covers import → local recovery reload → mocked upload/save → mocked Git reload, all byte-identical, and the 600MB storage warning appears after an unblocked save. JPEG/WebP regressions still pass. G3 review sheets are at `test-results/png-quality-dpr1.png` and `-dpr2.png`; `test-results/storage-meter-warning.png` shows the meter. Desktop Chrome emulation is not iPad/device evidence.
