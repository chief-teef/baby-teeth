## PNG runtime/resource gate

`node tests/desktop-media-workerd.mjs` exercised the actual local Windows workerd runtime, not only Node. It rejected CRC/order/truncation/trailing compressed data/inflate bomb/filter/APNG/interlace/type/dimension negatives; maximal accepted and 2048-chunk inputs passed. Initial 1600-square RGBA processing exceeded Free's 10ms CPU allowance, so the consistent processed PNG bound is 512px per side, 262,144 pixels and 300,000 bytes. JPEG bounds are unchanged.

At the retained bound the maximal fixture was 287,525 encoded / 1,049,088 decoded bytes. Across 25 samples, sampled active median/p95/max were 4.446/5.406/5.956ms. Actual child-process CPU averaged 4.6875ms per maximal request and 5.15625ms for the 2048-chunk fixture across 100 requests each. Heap/backing/embedder measurements stayed below 128MB. These are local estimates including host/IPC limitations, not observed production CPU or a guarantee for every Cloudflare host. Provider limits and deflate support were checked against official Cloudflare documentation; PNG structure against W3C PNG.
