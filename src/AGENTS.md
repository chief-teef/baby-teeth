# Desktop scrapbook studio
- Read root AGENTS.md and docs/desktop-scrapbook-spec.md. Authoring is desktop-first and mode-free: text interiors edit/select; external borders/handles move/reshape; photos drag directly. Preserve legacy ink/groups. No general pen or sticker system.
- New work uses nested v3 pages. Use entryPages/entryElements for enumeration and actual page arrays for mutation. Page/object IDs are stable; selection is page-local and global undo retains archive, entry, page and selection. Normalize empty pages only after commands/gestures; promotion preserves local coordinates and exposes overflow.
- src/page-composition.js owns stack geometry, movement, layers and page transfer. Main owns global commands/history, cloud/recovery and resize/rotation. Text modules own Tiptap interiors/selection/toolbar/paste; toolbar commands must retain editor hosts and IME, and form one undo entry.
- IndexedDB book-v3 is local recovery. Never overwrite book or immutable book-before-v3, or auto-merge divergent legacy tabs. Unknown recovery and failed preservation block autosave; retain raw export. Imports validate the complete copied/resulting archive before mutation.
- Failed uploads, expired login, disabled capabilities and conflicts retain local content/receipts. Async work targets matching current entry/object IDs and must not replace newer authored content. Save draft never publishes; public updates await exact-revision deployment.
- PNG alpha must survive both photo-processing and jpegForUpload. Shared PNG limits reflect measured Free runtime bounds; do not silently matte/convert PNG to JPEG or relax CSP connect-src for data URLs.
- Paper/header/text/fit use canonical shared CSS/geometry/fonts; decoration stays outside paper and public preview. Fit is derived, never persisted. Overflow remains editable/exportable; publication requires every page to fit. Per-entry palette uses full published-list context; draft/offline context is provisional.
- Fonts/defaults/favorites are local preferences independent of document data. Structured text accepts only shared allowlists; outside-editor paste must preserve native inputs/menus. Long paste rejects completely on limits, never truncates.
- editor-props supplies Otis and the tooth holder outside paper. Each impression is an ordinary transparent photo inserted through one command; no pickup/gap stamps. Stop animations/listeners on hide/preview/disposal and honor reduced motion.
- Music metadata and deployment status remain entry-level. Preserve stale-response protection, manual entry and approved Spotify attribution/artwork hosts.
- Test changes with relevant desktop-pages/text/shell/media browser suites and existing recovery/cloud/text regressions. Desktop emulation is not actual Safari/Pencil/Google Docs clipboard evidence.
