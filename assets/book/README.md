Original whole-pixel SVG sources are generated by `scripts/book-assets.mjs` and `scripts/desk-art.mjs`; the exported PNGs and original audio are CC0-1.0. Font files retain their SIL OFL licenses. Regeneration updates `public/book/manifest.json` checksums.

`spotify-icon.svg` is the unmodified black RGB icon from [Spotify's official icon pack](https://developer.spotify.com/images/guidelines/design/2024-spotify-logo-icon.zip). It is a Spotify trademark, **not CC0**; use it under the [Design & Branding Guidelines](https://developer.spotify.com/documentation/design). `spotify-logo.svg` is the unmodified black RGB full logo from [Spotify’s official full-logo pack](https://developer.spotify.com/images/guidelines/design/2024-spotify-full-logo.zip), with the same separate trademark terms. The player uses it on light pink with at least 70px width and half-icon-height clear space; it is never pixelated or recolored. Spotify artwork is remote entry metadata, never part of these original sprites. Keep it unmodified and link it back to Spotify with attribution.

VT323 digital player text uses the official Google Fonts v18 font under SIL OFL (`VT323-OFL.txt`). The full original TTF is kept here; `public/book/VT323-latin.ttf` is the official fonts.gstatic.com subset requested through Google Fonts CSS2 with U+0020–007E and U+00A0–00FF text. Other scripts use the monospace fallback. Regeneration retains the exported font and records its checksum/license; it does not copy the full source TTF into public output.

Caveat v23 supplies natural handwriting for opted-in text. Official Google Fonts variable Latin/Latin Extended WOFF2 sources are retained under SIL OFL (`Caveat-OFL.txt`) in assets/book and exported unchanged to public/book. Actual bold weights 400–700 are available; italic uses scoped browser style synthesis. Latin is 74,932 bytes; extended is another 29,472. Faces load only when used. Manifest regeneration records checksums and the official Google Fonts source.
